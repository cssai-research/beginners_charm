\# Local data



Large data files are not stored in this repository.



The manuscript workflow creates or uses the following local files:



1\. `disruption\_analysis.csv`  

&#x20;  Generated by the repository's BigQuery preprocessing pipeline.



2\. `sciscinet\_field\_reconstruction\_v2/analysis\_level0\_field\_memberships.parquet`  

&#x20;  Generated by `notebooks/01\_prepare\_sciscinet\_fields.ipynb`.



3\. `sciscinet\_exact\_career\_age\_v2/v9\_exact\_career\_age\_handoff.parquet`  

&#x20;  Generated by `notebooks/02\_prepare\_exact\_career\_age.ipynb`.



Additional intermediate SciSciNet-v2 files and caches are downloaded or generated locally as needed.



The final manuscript analyses are performed in

`notebooks/03\_manuscript\_analysis.ipynb`.
